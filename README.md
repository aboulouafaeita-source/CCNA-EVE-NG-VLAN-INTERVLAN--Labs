# CCNA EVE-NG Labs

Hands-on networking labs built in EVE-NG for CCNA practice, troubleshooting, and documentation.

## About This Repository
This repository contains my networking labs created in EVE-NG as part of my practical networking learning journey.

Each lab includes:
- Topology screenshots
- Device configurations
- Verification results
- Notes and troubleshooting observations

## Current Labs
- [Lab 01 - VLANs, Trunking, and Inter-VLAN Routing](labs/lab01-vlan-intervlan/README.md)
- [Lab 02 - ASA Firewall, VLAN Segmentation, and Inter-VLAN Communication](labs/lab02-asa-vlan-firewall/README.md)

## Skills Covered
- VLAN configuration
- Access and trunk ports
- Router and firewall interface configuration
- ASA subinterfaces
- Static routing
- Inter-VLAN communication
- Connectivity testing and troubleshooting
